# This Repository Has Been Archived

This repository is no longer active.

The `riscv-openocd` fork was originally used for the development of RISC-V support in OpenOCD.
That support has now been merged upstream, and ongoing development continues in the main
OpenOCD project at https://www.openocd.org.


## Submitting RISC-V Related Patches

Please submit your RISC-V related patches directly to the mainline OpenOCD project.
The Gerrit review system at review.openocd.org is used for code review.

Further links:

- Mainline OpenOCD repositories: https://openocd.org/pages/repos.html
- Developer's Guide: https://openocd.org/doc/doxygen/html/index.html


## Getting Support for OpenOCD

For support and project communication, upstream OpenOCD uses mailing lists and IRC.

See:

- https://openocd.org/pages/mailing-lists.html
